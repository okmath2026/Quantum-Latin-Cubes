# QLS(n) 基数谱研究笔记

起点：Zhang–Wang–Ji, *Quantum Latin Squares With all Possible Cardinalities*, JCD 2026
（n ≡ 0 mod 4, n ≥ 8 时谱 = [n, n²]\{n+1}；开放问题：其余阶数的谱）。

记 S(n) = { c : 存在基数为 c 的 QLS(n) }。已知：
S(2)={2}, S(3)={3}, S(4)={4,6,8,16}（Paczos 等 2021），
S(4m)=[4m,16m²]\{4m+1}（m≥2，Zhang–Wang–Ji），
n²∈S(n) 对所有 n≥4（Zang–Zheng–Tian–Shan 2026），
n+1∉S(n)（Zhang–Wang–Ji Lemma 3.1）。

---

## 引理 A（系式划分 / pattern 必要条件）

设 Q 为基数 c 的 QLS(n)。把放相同向量（相差相位）的格子归为一类，
则 n² 个格子被划分成 c 个**部分置换类**（同一类中任意两格不同行、不同列，
因为同行/同列的相同向量违反正交性）。

反之，"给定一个 c-类部分置换划分，是否存在向量赋值"是一个可计算的可行性
问题——这是数值搜索 (qls_search.py Part B) 的理论基础。

推论（计数约束）：c 个类的大小 s₁,…,s_c 满足 s_i ≤ n，Σs_i = n²，
故 c ≥ n，且 Σ(n − s_i) = n(c − n)。

## 引理 B（intercalate 旋转，+2 增量）

设经典 LS(n) 在行 {r₁,r₂}、列 {c₁,c₂}、符号 {i,j} 处有一个 intercalate。
把这 4 格替换为
  (r₁,c₁)=cosθ|i⟩+sinθ|j⟩, (r₁,c₂)=−sinθ|i⟩+cosθ|j⟩，
  第二行交换。所有行列约束自动保持（同列/同行其他格子的符号 ∉{i,j}）。
θ 一般位置时净增恰 2 个新向量（i,j 在别处仍各出现 ≥1 次，n≥4 时成立，
因为每个符号出现 n 次而 intercalate 只用 2 次）。

若 LS(n) 有 k 个两两相容（格子不交；共行/共列者符号对不交）的 intercalate，
用互不相同的一般角度旋转其中 t 个，得基数 n+2t 的 QLS(n)，t = 0,…,k。

## 命题 C（两行刚性定理）★ 新结果

**命题.** 设 Q 是 QLS(n)，其除两行 r₁,r₂ 外所有格子均为计算基向量
（即在这两行之外与某经典 LS(n) 一致）。则 Q 恰由该经典方在行 r₁,r₂ 上
旋转若干 intercalate 得到；特别地 card(Q) = n + 2t，t ≤ ⌊n/2⌋。

**证明骨架.** 列 c 中其余 n−2 格为计算基向量，故 (r₁,c),(r₂,c) 落在该列
两个剩余符号张成的 2 维子空间 span(a_c, b_c) 中。设 σ 为两行符号置换，
考虑其圈结构。对长度 ≥ 3 的圈：若某 u_k = α|a_k⟩+β|a_{k+1}⟩ 为真混合
（αβ≠0），则行 r₁ 正交性迫使 u_{k−1}=|a_{k−1}⟩、u_{k+1}=|a_{k+2}⟩，
于是 v_{k−1}=|a_k⟩（列内正交补），而 v_k 含非零 |a_k⟩ 分量，
与行 r₂ 内 ⟨v_{k−1},v_k⟩=0 矛盾。故长圈上全部经典。长度 2 的圈
（= intercalate）允许一个连续旋转参数。∎

**推论 C1.** 只修改两行的构造只能产生 c ≡ n (mod 2) 之外……准确说只能产生
c = n + 2t。因此：
- 对 n = 5：c = 8, 10, … 等"n+奇数"型基数必须修改 ≥ 3 行
  （深度量子结构），这解释了为何此类值难以构造；
- 与 S(4) = {4,6,8,16} 一致（6 = 4+2、8 = 4+4 均为两行型；奇数全缺席）。

**研究问题 C2.** 把命题 C 推广到"除 k 行外经典"（k=3,4），刻画可达增量集；
这将给出小基数段谱的完全刻画，并可能解释 S(4) 中 9–15 的空洞。

## 实验设计（qls_search.py）

- Part A：随机采样 LS(5)，找最大相容 intercalate 组 → 严格实现 c = 5+2t。
- Part B：对每个目标 c ∈ [6,25]：随机生成 c-类部分置换划分（由随机 LS(5)
  的符号类细分而来），交替投影（行/列极分解正交化 + 类内相位对齐平均）
  求可行点，scipy least_squares 抛光至 ≤1e−11，独立验证正交性与基数。
- 负对照：c = 6（已证不存在）应稳定失败。
- 解释注意：数值找到 = 存在性证据（可进一步有理化/符号化为严格证明）；
  找不到 ≠ 不存在，但反复失败提示非存在性猜想。

## 定理 D（intercalate 普查，已严格证明：穷举全部 161280 个 LS(5)）

1. LS(5) 中 intercalate 数目至多 4；
2. **可同时旋转（两两相容）的 intercalate 至多 1 个**
   （直方图：17280 个方无 intercalate——恰为循环群主类；其余 144000 个
   相容集大小恰为 1）；
3. 推论：**任何 LS(5) 中不存在符号对不相交的两个 intercalate**
   （否则它们自动相容）。等价地，σ_{ij}=π_i π_j^{-1} 型为 (2,3) 的
   符号对族是"相交族"。

因此 +2 旋转路线对 n=5 止步于 c=7，且划分 2+2+1 的双层构造（见框架 E）
最多给出 7：**c=9 不能由任何 ≤2 维的层结构产生**。

## 框架 E（层分解 / quantum t-plex）★ 核心新框架

把 n 个符号划分为组 n = t₁+…+t_k。第 i 组的 tᵢn 个格子（一个 tᵢ-plex 层）
整体取值于这 tᵢ 个计算基向量张成的**全局 tᵢ 维子空间**；层与层正交，
互不约束。层内约束：每行/每列中该层的 tᵢ 个格子构成该子空间的 ONB。

记 P(t,n) = 量子 t-plex 层的可达向量数集合，则
  **S(n) ⊇ { Σᵢ aᵢ : aᵢ ∈ P(tᵢ,n)，划分 n = Σtᵢ }**。

已知/已算：
- P(1,n) = {1}；
- P(2,n)：层 = 两个置换矩阵之并，按 σ 的圈分解，每圈独立携带一个
  旋转角，圈内向量为 u, u⊥ 交替 ⇒ 每圈贡献 2。
  P(2,5) = {2,4}（4 需 σ 型 (2,3)，即该符号对带 intercalate）；
- n=4 一致性检验：层框架给出 {4,6,8} ∪ {16} = S(4)，完全吻合（重要旁证）；
- n=5 证书剖面与层结构吻合：
  c=12 = 2 + 10（两个经典符号 + 3 维层贡献 10），
  c=21 = 1 + 20（一个经典符号 + 4 维层全分明），
  c=7 = 3 + 4（intercalate 旋转 = 2 维层一圈旋转）。

## 定理 H（互补刚性，n=5；120/120 数值二分，待符号化证明）

LS(5) 中固定符号对 {i,j}，其余三个符号构成 3 层。则：
  **{i,j} 带 intercalate（σ 型 (2,3)）⟺ 互补 3 层刚性（仅经典解）。**
等价图论形式：3-正则二部模式（= 2-因子之补）量子柔性 ⟺ 该 2-因子是
单个 10-圈。5×5 上此类模式同构意义下仅两种 ⇒ 可用 Gröbner 基对两个
具体代数簇逐一严格证明（升级为定理的明确路径）。

推论：划分 3+2 只能给出 {3}+{2,4} ∪ {5,10}+{2} = **{5,7,12}**。
（柔性 3 层与可旋转对互斥。）

## 定理 I（c=8、c=9 非存在性，模式级穷举 + 子空间障碍）★ 已证

规范化首行为计算基后，c=8 只余 3 个新向量类。穷举全部 34560 个规范
符号模式（c8_pattern_search.py），每个模式触发三种初等障碍之一：
  same_2d_triangle（2 维空间无三两两正交向量）8640 个；
  same_2d_path（2 维中 x⊥y⊥z ⇒ x≅z）23040 个；
  two_2d_one_3d_triangle（第三向量被逼成坐标向量）2880 个。
⇒ **8 ∉ S(5)**。同法 9224 个 c=9 模式全部不可行 ⇒ **9 ∉ S(5)**。
（c9_pattern_probe.py；两者均为可发表的组合证明，建议人工复核枚举完备性。）
